# Deployed Personnel Support Center

A premium fictional/demo personnel-support portal built with React + Vite.

## Important
This is a fictional demonstration platform. It is **not affiliated with or operated by any real military, government, intelligence agency, or defense organization**.

Do not collect classified information, passwords, security credentials, precise military locations, troop movements, operational details, weapons information, or sensitive intelligence.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite address shown in the terminal.

## Images

The hero currently uses a remote Unsplash image URL. For a fully self-contained GitHub version, download a properly licensed deployment/personnel photograph into `public/images/` and change the hero background URL in `src/index.css`.

The news cards link to public Reuters reporting and are intentionally secondary to the Personnel Support Center.
